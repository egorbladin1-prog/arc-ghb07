# BANNY SHOP BotPay V7 — Termux + Neon Mini App

Полноценный Telegram-магазин: Neon Mini App + покупки через Telegram-бота + оплата чеком + админская обработка.

## Что внутри
- Neon UI, баннер, анимации, карточки товаров
- Категории и поиск
- BANNY PREMIUM V3
- Покупка через Telegram-бота
- Реквизиты, отправка чека, подтверждение/отклонение админом
- Промокоды, отзывы, профиль, заказы
- Админ-панель: статистика, товары, категории, промокоды, пользователи, чаты, заказы
- Встроенный API Mini App

## Запуск на втором Android через Termux
1. Установи Termux и выдай доступ к хранилищу.
2. Положи проект в `~/banny_shop`.
3. Один раз задай токен бота:

```bash
export BOT_TOKEN='ТОКЕН_ТВОЕГО_БОТА'
```

4. Запускай:

```bash
cd ~/banny_shop
./start_termux.sh
```

Скрипт сам:
- ставит зависимости;
- запускает локальный Mini App на порту 8080;
- поднимает HTTPS-туннель Cloudflare;
- получает публичный URL;
- передаёт его боту как `MINIAPP_URL`;
- запускает бота.

URL туннеля меняется после полного перезапуска. Скрипт каждый раз автоматически получает новый URL и настраивает кнопку Mini App в Telegram.

## Важно
Телефон должен быть включён, иметь интернет и не выгружать Termux из памяти. Для 24/7 отключи оптимизацию батареи для Termux.

Не публикуй `BOT_TOKEN` или GitHub-токены.
