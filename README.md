# BANNY SHOP — Mini App + Bot

Рабочая сборка Telegram-магазина с Mini App, заказами, ручной проверкой чеков и админ-панелью.

## Возможности
- каталог, категории и товары;
- карточка товара с коротким описанием и полным функционалом;
- BANNY PREMIUM V3 остаётся постоянным товаром;
- создание товаров из админки: категория → название → цена → описание → функционал → фото/пропуск;
- ручная оплата по реквизитам и отправка фото чека в бот;
- статусы заказа: **Оплачивается → Проверяется → Оплачено / Отклонено**;
- Mini App с каталогом, покупками, промокодом и профилем;
- админ-панель с пользователями, поиском, заказами и чатами;
- Telegram-like чат поддержки с unread-счётчиками, историей, поиском и автообновлением;
- серверная проверка Telegram `initData`.

## Запуск в Termux
```bash
pkg update
pkg install python
pip install -r requirements.txt
export BOT_TOKEN='ВАШ_ТОКЕН_БОТА'
export ADMIN_ID='ВАШ_TELEGRAM_ID'
export CARD_NUMBER='2204120135107775'
export MINIAPP_HOST='0.0.0.0'
export MINIAPP_PORT='8080'
export MINIAPP_URL='https://ВАШ-ДОМЕН.example'
python bot.py
```

Mini App раздаётся из папки, где находится `bot.py`. Для Telegram нужен публичный **HTTPS** адрес.

## Данные оплаты
- Карта: **МИР**
- Реквизиты: задаются через `CARD_NUMBER`
- Банк: **YooMoney**
- После перевода пользователь отправляет фото чека в чат с ботом.

## Безопасность
Не храните токен бота, ключи платёжных систем или другие секреты в Git. Используйте переменные окружения. Если токен когда-либо попадал в публичный репозиторий/чат, перевыпустите его через BotFather.
